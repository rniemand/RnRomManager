# CLAUDE.md

## Exploration

Use the `explore-haiku` subagent (`.claude/agents/explore-haiku.md`) for all codebase exploration and search sweeps. Only use the larger `Explore` or `general-purpose` agents when the task needs deeper reasoning than locating code (e.g. a review, audit or design judgement). Quick lookups with a known target can still use Grep/Read directly.
