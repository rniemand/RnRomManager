DOSBox Pure (EmulatorJS core "dosbox_pure", MS-DOS)
===================================================

Files: dosbox_pure-thread-wasm.data, dosbox_pure-thread-legacy-wasm.data and
       reports/dosbox_pure.json
       (npm @emulatorjs/core-dosbox_pure 4.2.3), copied unchanged. The package
       has threaded payloads only (its report sets requireThreads), so
       RnRomManager plays MS-DOS only in a cross-origin isolated page.

Corresponding source:
- Core: https://github.com/EmulatorJS/dosbox-pure/tree/bdabec1651380f3f736eecff8d859090ae822f9b
  Fork of https://github.com/schellingb/dosbox-pure. The binaries carry no
  commit string; the payload's report records a build started at
  2025-06-14T19:59:34Z, and the fork's main branch was then at bdabec1
  (2025-06-13). The payload's license.txt is byte-identical to LICENSE at that
  commit.
- Built with the cores.json entry {"makescript": "Makefile", "buildpath":
  "./", "arguments": []} and RetroArch's "build-emulatorjs.sh --threads".
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt.
