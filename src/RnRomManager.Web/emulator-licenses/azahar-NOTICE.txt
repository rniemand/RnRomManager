Azahar (EmulatorJS core "azahar", Nintendo 3DS)
===============================================

Files: azahar-thread-wasm.data and reports/azahar.json from
https://cdn.emulatorjs.org/4.3.0-pre/data/cores/, copied unchanged and pinned
by SHA-256 in emulatorjs-next.json. They belong to the EmulatorJS 4.3.0-pre
prerelease (https://github.com/EmulatorJS/EmulatorJS/tree/5628818822054610a2f06e61a6dc802fd1a3681f,
the v4.3.0-pre tag), whose scripts RnRomManager vendors side by side with
4.2.3 for this core only (licenses/emulatorjs-4.3.txt). Only a threaded
WebGL 2 payload exists (its report sets requireThreads and requiresWebgl2),
so RnRomManager plays Nintendo 3DS only in a cross-origin isolated page.

Corresponding source:
- Core: https://github.com/EmulatorJS/azahar/tree/62cfcfb5e488f158f5f7ba83b725bb0ddd04da44
  Fork of https://github.com/azahar-emu/azahar. The payload names no
  revision; its report records a build started at 2026-05-17T17:40:04Z, and
  the newest commit on the fork's default branch
  (warmenhoven/dev/azahar_libretro) before then was 62cfcfb (2026-05-12), so
  the revision was inferred that way. The payload's build.json says version
  2.0.3 (minimumEJSVersion 4.3.0).
- Built with the payload's core.json: CMake, build dir build-emscripten,
  -DCMAKE_BUILD_TYPE=Release, -DCMAKE_CXX_FLAGS="-pthread -msimd128",
  -DCMAKE_C_FLAGS="-pthread -msimd128", -DENABLE_LIBRETRO=ON, -DENABLE_QT=OFF,
  -DENABLE_SDL2=OFF, -DENABLE_TESTS=OFF, -DENABLE_CUBEB=OFF,
  -DENABLE_OPENAL=OFF, -DENABLE_VULKAN=OFF, -DENABLE_LIBUSB=OFF,
  -DENABLE_SCRIPTING=OFF, -DENABLE_WEB_SERVICE=OFF,
  -DENABLE_SOFTWARE_RENDERER=OFF, -DENABLE_GENERIC=ON; output archive
  azahar_libretro_emscripten.a.
- The binary is a RetroArch frontend (EmulatorJS fork, GPL-3.0-or-later,
  retroarch-LICENSE.txt) statically linked with the core; the payload doesn't
  record the RetroArch revision (COMMON-BUILD.txt describes the 4.2.3 builds).

LibreSSL):

RnRomManager.
