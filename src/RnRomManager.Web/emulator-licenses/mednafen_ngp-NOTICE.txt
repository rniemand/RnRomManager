Beetle NeoPop (EmulatorJS core "mednafen_ngp", Neo Geo Pocket / Neo Geo Pocket Color)
=====================================================================================

Files: mednafen_ngp-wasm.data, mednafen_ngp-legacy-wasm.data
       (npm @emulatorjs/core-mednafen_ngp 4.2.3)

Corresponding source:
- Core: https://github.com/EmulatorJS/beetle-ngp-libretro/tree/10f91c135bb27ce23407fbb1fa2f072794da2fd7
  (2024-12-10; version string "v1.29.0.0 10f91c1" in both binaries).
- Built with the cores.json entry {"makescript": "Makefile", "buildpath":
  "./", "arguments": []} and platform=emscripten, whose Makefile branch sets
  STATIC_LINKING = 1; the Makefile always sets NEED_BLIP = 1.
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt.
