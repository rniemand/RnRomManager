Beetle PCE (EmulatorJS core "mednafen_pce", TurboGrafx-16 / PC Engine)
======================================================================

Files: mednafen_pce-wasm.data, mednafen_pce-legacy-wasm.data
       (npm @emulatorjs/core-mednafen_pce 4.2.3)

Corresponding source:
- Core: https://github.com/EmulatorJS/beetle-pce-libretro/tree/e1ac90d5a97ad328c51b8b01e68da8af5faa1579
  (version string "v1.29.0 e1ac90d" in both binaries). Fork of
  https://github.com/libretro/beetle-pce-libretro, which holds the same commit.
- Built with the cores.json entry {"makescript": "Makefile", "buildpath":
  "./", "arguments": []} and platform=emscripten, whose Makefile branch sets
  STATIC_LINKING = 1; the Makefile always sets HAVE_CHD = 1, NEED_TREMOR = 1
  and NEED_BLIP = 1, and leaves SYSTEM_ZLIB and SYSTEM_LIBCHDR unset.
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt.

Beetle PCE is a port of the PC Engine module of Mednafen, by the Mednafen
team (mednafen/ and the per-file headers); the libretro port by its
contributors.
