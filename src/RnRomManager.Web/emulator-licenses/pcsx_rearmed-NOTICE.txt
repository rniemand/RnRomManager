PCSX ReARMed (EmulatorJS core "pcsx_rearmed", PlayStation)
==========================================================

Files: pcsx_rearmed-wasm.data, pcsx_rearmed-legacy-wasm.data
       (npm @emulatorjs/core-pcsx_rearmed 4.2.3)

Corresponding source:
- Core: https://github.com/EmulatorJS/pcsx_rearmed/tree/f29871dde1742cafb0ab56ba33636a8600bbbd80
  (version string "f29871d" in both binaries, the libretro revision of that
  checkout; the "092633f8" the core prints is the tracked frontend/revision.h
  at that commit). Fork of https://github.com/libretro/pcsx_rearmed.
- Submodule: frontend/libpicofe at
  https://github.com/notaz/libpicofe/tree/ee0dca9e10ef44d7900c1158cd8025eb86064aeb
  (headers only: frontend/main.c includes them; no libpicofe source file is
  compiled for the libretro platform). deps/lightning/gnulib is inactive and
  unused.
- Built with the cores.json entry {"makescript": "Makefile.libretro",
  "buildpath": "./", "arguments": []} and platform=emscripten (plus
  EMULATORJS_LEGACY=1 for the legacy variant, which changes nothing in this
  core's Makefile). Makefile.libretro's emscripten branch sets DYNAREC = 0
  (interpreter only; lightrec, GNU lightning and the ARM dynarec are not
  compiled), NO_PTHREAD = 1, USE_ASYNC_CDROM = 0, HAVE_PHYSICAL_CDROM = 0,
  WANT_ZLIB = 0, NO_MMAP = 1, STATIC_LINKING = 1, -msimd128 -ftree-vectorize;
  the defaults leave HAVE_CHD = 1 and BUILTIN_GPU = peops (the P.E.Op.S. soft
  GPU in plugins/dfxvideo with plugins/gpulib). The other compiled sources are
  libpcsxcore (core, interpreter, GTE, HLE BIOS), plugins/dfsound and
  frontend/libretro.c, main.c, plugin.c and cspace.c.
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt. RetroArch's
  emulatorjs/build-emulatorjs.sh links this core with a 512 MiB initial heap
  and the frontend's own CHD support off (HAVE_CHD=0; the core reads CHD
  itself), WebGL 2 for the plain variant and WebGL 1 for legacy
  (reports/pcsx_rearmed.json: defaultWebGL2).

The PlayStation BIOS is not part of this core or of RnRomManager. Without one
the core uses its built-in HLE BIOS (libpcsxcore/psxbios.c, GPL-2.0-or-later);
the operator may supply scph5501.bin.
