Beetle WonderSwan (EmulatorJS core "mednafen_wswan", WonderSwan / WonderSwan Color)
==================================================================================

Files: mednafen_wswan-wasm.data, mednafen_wswan-legacy-wasm.data
       (npm @emulatorjs/core-mednafen_wswan 4.2.3)

Corresponding source:
- Core: https://github.com/EmulatorJS/beetle-wswan-libretro/tree/fbc945dc10f2ff730c739509fe414dfb2eb5c6ce
  (2024-12-10; version string "v0.9.35.1 fbc945d" in both binaries).
- Built with the cores.json entry {"makescript": "Makefile", "buildpath":
  "./", "arguments": []} and platform=emscripten, whose Makefile branch sets
  STATIC_LINKING = 1; the Makefile always sets NEED_BLIP = 1.
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt.
