DeSmuME (EmulatorJS core "desmume", Nintendo DS)
=================================================

Files: desmume-wasm.data, desmume-legacy-wasm.data
       (npm @emulatorjs/core-desmume 4.2.3)

Corresponding source:
- Core: https://github.com/EmulatorJS/desmume/tree/c6317a446c3146ee30efe55a5c0763975a100ce7
  (the string "git c6317a4" in both binaries; the fork's master head from
  2024-12-10 through the build date). Fork of https://github.com/libretro/desmume.
- Built with the core.json entry {"makescript": "Makefile.libretro",
  "buildpath": "./desmume/src/frontend/libretro", "arguments": []} and
  platform=emscripten, so desmume/src/frontend/libretro/Makefile.libretro's
  defaults apply: DEBUG = 0, HAVE_LIBFAT = 1, EMULATORJS_THREADS = 0 (no
  -pthread), STATIC_LINKING = 1, no JIT (DESMUME_JIT and DESMUME_JIT_ARM unset,
  so utils/AsmJit and arm_jit.cpp are not compiled) and no OpenGL renderer
  (DESMUME_OPENGL unset). Makefile.common lists the compiled sources: the
  DeSmuME core (ARM interpreters, MMU, GPU, the software 3D rasterizer, SPU,
  slot-1/slot-2 add-ons, cheats, saves), the libretro frontend (libretro.cpp)
  and the components below. HAVE_LIBAGG, HAVE_LIBSOUNDTOUCH, Lua, the Windows
  winpcap headers and the OpenGL headers are not used by this build.
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt (both binaries
  carry RetroArch "6dd4353").

RnRomManager. RnRomManager never supplies them: the core uses its built-in
HLE BIOS and firmware.

The payloads ship no licence text (the package's "license" field is empty);
this file and the licence files named above supply it.
