Yabause (EmulatorJS core "yabause", Saturn)
===========================================

Files: yabause-wasm.data, yabause-legacy-wasm.data
       (npm @emulatorjs/core-yabause 4.2.3)

Corresponding source:
- Core: https://github.com/EmulatorJS/yabause/tree/e24ebfca357bf70732a77a58c14491f13209a1cd
  (version string "0.9.15 e24ebfc" in both binaries). Fork of
  https://github.com/libretro/yabause.
- Built with the core.json entry {"makescript": "Makefile",
  "buildpath": "./yabause/src/libretro", "arguments": []} and
  platform=emscripten, so yabause/src/libretro/Makefile's defaults apply:
  DYNAREC = 0 (interpreter only), HAVE_MUSASHI = 1, ENABLE_ZLIB = 1,
  ENABLE_CHD = 1, USE_SCSP2 = 0, ENABLE_TSUNAMI = 0, USE_PLAY_JIT = 0,
  HAVE_GRIFFIN = 0, EMULATORJS_THREADS = 0 (no -pthread), STATIC_LINKING = 1,
  -msimd128 -ftree-vectorize. Makefile.common lists the compiled sources:
  the Yabause core, the software video renderer (vidsoft.c, titan), the SCSP,
  the libretro frontend (libretro.c) and the components below.
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt (both binaries
  carry RetroArch "6dd4353").
