FCEUmm (EmulatorJS core "fceumm", NES)
=======================================

Files: fceumm-wasm.data, fceumm-legacy-wasm.data
       (npm @emulatorjs/core-fceumm 4.2.3)

Corresponding source:
- Core: https://github.com/EmulatorJS/libretro-fceumm/tree/d9d7e141274d07186b6a871ca2919b6f13cfb2f9
  (version string "d9d7e14" in both binaries). Fork of
  https://github.com/libretro/libretro-fceumm. No submodules.
- Built with the cores.json entry {"makescript": "Makefile.libretro",
  "buildpath": "./", "arguments": []} and platform=emscripten (plus
  EMULATORJS_LEGACY=1 for the legacy variant, which changes nothing in this
  core's Makefile), so Makefile.libretro's defaults apply: HAVE_NTSC = 1,
  STATIC_LINKING = 1, EXTERNAL_ZLIB = 1, -O3 -DNDEBUG. The compiled sources are
  Makefile.common's SOURCES_C: src/*.c listed there, src/boards/*.c,
  src/input/*.c, src/ntsc/nes_ntsc.c and src/drivers/libretro/*.c.
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt. RetroArch's
  emulatorjs/build-emulatorjs.sh links this core with the default 128 MiB
  initial heap, WebGL 2 for the plain variant and WebGL 1 for legacy.
