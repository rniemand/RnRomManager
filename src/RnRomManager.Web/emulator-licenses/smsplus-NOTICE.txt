SMS Plus GX (EmulatorJS core "smsplus", Game Gear and Master System)
====================================================================

Files: smsplus-wasm.data, smsplus-legacy-wasm.data
       (npm @emulatorjs/core-smsplus 4.2.3)

Corresponding source:
- Core: https://github.com/EmulatorJS/smsplus-gx/tree/c642bbd0680b5959180a420036108893d0aec961
  (version string "1.8 c642bbd" in both binaries; master at build time and
  still master). Fork of https://github.com/libretro/smsplus-gx.
- Built with the cores.json entry {"makescript": "Makefile.libretro",
  "buildpath": "./", "arguments": []}, so Makefile.libretro's defaults apply:
  SOUND_ENGINE = maxim_sn76489, ZIP_SUPPORT = 0, HAVE_NTSC = 1.
- RetroArch, build scripts and compiler: see COMMON-BUILD.txt.
